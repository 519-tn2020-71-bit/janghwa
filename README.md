# 젖은 발자국 — 철산 괴담 수사록

고전 소설 「장화홍련전」의 짜임(새 사또와 원혼, 누명, 꾸민 증거, 자백과 변명)을 빌려 새로 지은 수업용 추리 게임입니다(고1 공통국어, 화법·독서: 추론하며 듣기, 발화 의도 파악, 책임감 있게 듣기).

- 바로 하기: https://519-tn2020-71-bit.github.io/wet-footprints/
- 1~5장(4차시): 새로 부임한 철산 현감이 되어 증언을 듣고, 모순을 찔러 증거를 내밀고, 말의 속뜻을 판정합니다. 3차시 끝(중간)과 4차시 끝(최종)에 기록을 구글 설문지로 냅니다.
- 사건과 인물은 모두 지어낸 것입니다. 갑자기 놀라게 하는 장면이 있으며, 표지에서 ‘깜짝 효과 약하게’로 바꿀 수 있습니다.
- AI 자유 심문의 대답은 AI가 꾸민 말입니다. 질문과 대답은 담당 교사가 볼 수 있습니다(반·번호만 남김).
- 그림은 AI로 생성했고, 배경음과 효과음은 게임 안에서 직접 합성합니다.
