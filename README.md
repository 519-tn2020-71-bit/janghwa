# 철산의 귀

고전 소설 「장화홍련전」을 바탕으로 한 수업용 심문 RPG입니다(고1 공통국어, 화법·독서: 추론적 듣기와 발화 의도 파악).

- 바로 하기: https://519-tn2020-71-bit.github.io/janghwa/
- 1~4장: 새로 부임한 철산 부사가 되어 진술을 듣고 속뜻을 판정합니다. 5장: 배좌수의 귀로 같은 말을 다시 듣습니다(회상). 6장(끝장)은 고를 때만 읽습니다.
- 붉은 낙관(本)이 찍힌 문장은 다빈치맵의 「장화홍련전」 현대어 풀이본 문장입니다. 원문의 오자도 고치지 않고 그대로 두었습니다.
- AI 자유 심문의 대답은 AI가 꾸민 말이며 화면에 “AI가 꾸민 대답 · 본문 아님”으로 표시합니다. 질문과 대답은 담당 교사가 볼 수 있습니다(반·번호만 남김).
- 그림은 AI로 생성했고, 배경음과 효과음은 게임 안에서 직접 합성합니다.
